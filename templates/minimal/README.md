# Gothic Forge - Minimal Template

A bare-bones Gothic Forge project with just the essentials.

## What's Included

- ✅ Basic HTTP server with Chi router
- ✅ Health check endpoint (`/healthz`)
- ✅ Environment configuration
- ✅ Structured logging
- ✅ Graceful shutdown
- ❌ No database
- ❌ No authentication
- ❌ No cache
- ❌ No frontend templates

## Quick Start

```bash
# Start development server
gforge dev

# Run tests
gforge test

# Deploy to production
gforge deploy --live
```

## Project Structure

```
.
├── cmd/
│   └── server/
│       └── main.go          # Application entry point
├── internal/
│   └── server/
│       └── server.go        # HTTP server setup
├── .env.example             # Environment variables
├── providers.yaml           # Provider configuration (minimal)
└── go.mod                   # Go dependencies
```

## Available Endpoints

- `GET /` - Welcome message
- `GET /healthz` - Health check (returns 200 OK)

## Environment Variables

```bash
# Application
APP_ENV=development
SITE_BASE_URL=http://127.0.0.1:8080

# Server
HTTP_HOST=127.0.0.1
HTTP_PORT=8080

# Security
JWT_SECRET=<auto-generated>
```

## Adding Features

### Add Database

```bash
# Switch to PostgreSQL provider
gforge add db --provider=postgresql

# Or use CockroachDB for production
gforge add db --provider=cockroachdb
```

### Add Authentication

```bash
gforge add auth
```

### Add Cache

```bash
gforge add cache --provider=valkey
```

## Deployment

This minimal template can be deployed to:

1. **Cloudflare Pages** (static export)
   ```bash
   gforge export
   gforge deploy pages --run
   ```

2. **Leapcell** (full backend)
   ```bash
   gforge deploy --live
   ```
