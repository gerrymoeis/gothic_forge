# Gothic Forge - Blog Template

A complete blog application with CRUD operations, database integration, and admin interface.

## What's Included

- ✅ Post management (Create, Read, Update, Delete)
- ✅ Database schema and migrations
- ✅ Templ templates for blog UI
- ✅ Admin interface for content management
- ✅ RSS feed generation
- ✅ SEO optimization (meta tags, sitemap)
- ✅ Markdown support for posts
- ✅ Categories and tags
- ✅ Draft/Published status
- ✅ Responsive design

## Quick Start

```bash
# Install dependencies
gforge install

# Run migrations
gforge db --migrate

# Start development server
gforge dev

# Visit: http://localhost:8080
```

## Database Schema

### Posts Table

```sql
CREATE TABLE posts (
    id SERIAL PRIMARY KEY,
    title VARCHAR(255) NOT NULL,
    slug VARCHAR(255) UNIQUE NOT NULL,
    content TEXT NOT NULL,
    excerpt TEXT,
    author VARCHAR(100),
    status VARCHAR(20) DEFAULT 'draft',
    published_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_posts_slug ON posts(slug);
CREATE INDEX idx_posts_status ON posts(status);
CREATE INDEX idx_posts_published_at ON posts(published_at);
```

## Available Endpoints

### Public Routes
- `GET /` - Homepage (list of published posts)
- `GET /post/:slug` - Single post view
- `GET /rss` - RSS feed
- `GET /sitemap.xml` - Sitemap for SEO

### Admin Routes
- `GET /admin` - Admin dashboard
- `GET /admin/posts` - Manage posts
- `GET /admin/posts/new` - Create new post
- `GET /admin/posts/:id/edit` - Edit post
- `POST /admin/posts` - Save new post
- `PUT /admin/posts/:id` - Update post
- `DELETE /admin/posts/:id` - Delete post

## Deployment

### Option 1: Full Stack (Recommended)

```bash
# Set up database provider
gforge secrets --set COCKROACH_API_KEY=<your-key>

# Deploy with database
gforge deploy --live
```

### Option 2: Static Export

```bash
# Export as static site
gforge export

# Deploy to Cloudflare Pages
gforge deploy pages --run
```

## Customization

### Change Theme

Edit `app/static/styles/blog.css` to customize colors and layout.

### Add Categories

Extend the database schema:

```sql
CREATE TABLE categories (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    slug VARCHAR(100) UNIQUE NOT NULL
);

CREATE TABLE post_categories (
    post_id INTEGER REFERENCES posts(id),
    category_id INTEGER REFERENCES categories(id),
    PRIMARY KEY (post_id, category_id)
);
```

### Add Comments

Use a third-party service like Disqus or implement your own:

```bash
gforge add comments --provider=disqus
```
